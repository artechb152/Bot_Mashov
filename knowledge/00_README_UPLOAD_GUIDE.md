# חבילת Knowledge לבוט חניכה ומשוב - מדריך העלאה והטמעה

## מטרת החבילה
חבילה זו מיועדת להעלאה ל-Knowledge / Skills / מסמכי עזר של בוט פנים-ארגוני מבוסס LLM, עבור סגלי הדרכה, חונכים, מפקדים ומפתחי הכשרה. הבוט נועד לסייע בתכנון חניכה, ניסוח משוב, ניתוח מסמכים, בניית שיחות משוב, תחקירים/AAR, תכנון תרגול המשך והערכת איכות תהליכי חניכה.

## עקרון יסוד
הבוט אינו “מחולל תשובות כלליות”. הוא מנוע סיוע מקצועי שמתרגם מידע על ביצוע לפעולה חינוכית/פיקודית/הדרכתית:

**יעד/סטנדרט → תצפית/עדות → פער → משמעות → שיחה/חקירה → פעולה → מעקב**

## סדר העלאה מומלץ
אם המערכת מאפשרת להעלות כמה קבצים, העלה אותם בסדר הבא:

1. `01_SYSTEM_PROMPT.md` - כהנחיית מערכת / system prompt / agent instruction. אם אין מקום נפרד להנחיית מערכת, העלה אותו ראשון והגדר אותו כקובץ בעל עדיפות גבוהה.
2. `02_KNOWLEDGE_CORE_DOCTRINE.md` - עקרונות הליבה של הבוט.
3. `03_GLOSSARY.md` - מילון מושגים ארגוני.
4. `04_FEEDBACK_PRINCIPLES.md` - עקרונות משוב וחניכה.
5. `05_MODELS_SBI_R2C2_AAR_GROW.md` - מודלים וכלים.
6. `06_PLAYBOOKS.md` - תרחישי עבודה ותהליכים.
7. `07_TEMPLATES.md` - תבניות מוכנות.
8. `08_RUBRICS.md` - מחוונים להערכת איכות.
9. `09_EXAMPLES_GOOD_BAD.md` - דוגמאות משוב חלש/משופר.
10. `10_DOCUMENT_REVIEW_GUIDE.md` - ניתוח מסמכי הדרכה.
11. `11_SENSITIVE_CASES_AND_GUARDRAILS.md` - גבולות, סיכונים ומקרים רגישים.
12. `12_EVALUATION_GOLDEN_TESTS.md` - בדיקות איכות לבוט.
13. `13_SOURCE_REGISTER.md` - רישום מקורות חיצוניים וסטטוס אמינות.

בנוסף קיים קובץ `mentor_feedback_knowledge_combined.md` שמאחד את כל החבילה למסמך אחד, למקרה שהמערכת תומכת בהעלאת קובץ יחיד.

## קדימות מקורות
בכל תשובה של הבוט, יש להשתמש בקדימות הבאה:

1. הוראות מערכת וגבולות הבוט.
2. מסמכים פנימיים רשמיים של הארגון: תו״ל, נהלים, סטנדרטים, כשירויות, הוראות בטיחות, טפסים מאושרים.
3. מסמכים פנימיים לא-רשמיים: דוגמאות, מערכים, תחקירים, לקחים.
4. כרטיסי ידע מקצועיים בחבילה זו.
5. ידע כללי/מחקרי חיצוני.

אם יש סתירה בין מקור פנימי רשמי לבין ידע כללי, המקור הפנימי הרשמי גובר, כל עוד אינו סותר דין, בטיחות, אתיקה או מדיניות אבטחת מידע.

## אופן שימוש מומלץ
הבוט צריך להחזיר בדרך כלל תוצר מעשי: נוסח שיחה, שאלות חניכה, רשימת חוזקות/פערים, תרגול המשך, תבנית AAR, מחוון או הצעת תיקון למסמך.

## כלל זהב
בכל פעם שהבוט נותן משוב או מסייע לנסח משוב, עליו לכלול לפחות ארבעה רכיבים:

1. מה הסטנדרט או היעד?
2. מה נצפה בפועל?
3. מה ההשפעה או המשמעות?
4. מה הפעולה הבאה ומה מדד ההצלחה?

## מה חסר ונדרש להשלים בארגון
חבילה זו אינה כוללת מסמכים פנימיים שלכם. כדי להגיע לרמת דיוק גבוהה, יש להוסיף בהמשך:

- תו״ל הדרכה וחניכה פנימי.
- הגדרות תפקיד של חונך, מדריך, מפקד, מעריך.
- טפסי משוב ותצפית קיימים.
- סטנדרטים לכל קורס/כשירות.
- דוגמאות אמיתיות שעברו אנונימיזציה.
- נהלי בטיחות, משמעת, פרטיות וסיווג.
- לקחים ותחקירים לא מסווגים.

## שכבת סימולציות
נוספה לחבילה שכבת סימולציות ייעודית:

14. `14_SIMULATION_ENGINE.md` - כללי הפעלת מצב סימולציה, זרימת שיחה, פקודות שליטה, אופן משחק דמות ומתן משוב לאחר התרגול.
15. `15_SIMULATION_SCENARIO_LIBRARY.md` - מאגר תרחישים מוכנים לתרגול שיחות חניכה, משוב, AAR, התנגדות, בטיחות ושיחות סגל.

המלצה: להעלות את שני הקבצים האלה לאחר קבצי המודלים, התבניות והמחוונים, או להעלות את הקובץ המאוחד המעודכן.

## שכבת תגובות משמעתיות וענישה הדרכתית

16. `16_DISCIPLINE_AND_EDUCATIONAL_RESPONSES.md` - שכבת ידע לתגובות משמעתיות בהקשר הדרכתי: תרגול נוסף, מניעת חופשה, שעות ביציאה, שבת לימודית, נזיפה פיקודית ודין משמעתי, עם דגש על סמכות, מידתיות, תיעוד וגבולות הבוט.
