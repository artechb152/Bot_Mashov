# knowledge/ — מאגר הידע

תיקייה זו היא **מקור האמת** לתוכן מאגר הידע. כל קובץ `.md` כאן הוא מסמך ידע אחד.

הסנכרון (`npm run knowledge:sync`) קורא את הקבצים, מחלץ את ה-metadata, ומסנכרן אותו
למסד הנתונים (מודל `KnowledgeDocument`). האתר (`/knowledge` ו-`/knowledge/[slug]`)
מציג את הרשומות מה-DB, ואת תוכן ה-Markdown מהקובץ.

> **אין כרגע שום חיבור AI ואין קריאות API חיצוניות.** זו רק סריקה, סנכרון וצפייה.

## מבנה קובץ

כל קובץ מתחיל ב-frontmatter (בין `---`) ואחריו תוכן Markdown רגיל:

```md
---
title: "שם המסמך"
description: "תיאור קצר"
category: "חניכה"
unit: "יחידה 1"
order: 1
tags:
  - "חניכה"
  - "משוב"
status: "active"
---

# כותרת

תוכן Markdown…
```

### השדות

| שדה | חובה? | הסבר |
| --- | --- | --- |
| `title` | כן | כותרת המסמך |
| `description` | לא | תיאור קצר שמופיע ברשימה |
| `category` | לא | קטגוריה חופשית בעברית (למשל "חניכה") |
| `unit` | לא | יחידה / נושא (למשל "יחידה 1") |
| `order` | לא | מספר לסידור הרשימה (ברירת מחדל 0) |
| `tags` | לא | רשימת תגיות |
| `status` | לא | סטטוס חופשי (למשל "active", "draft", "archived") |

- ה-**slug** (המזהה ב-URL) נגזר משם הקובץ (למשל `00_example.md` → `00_example`),
  או מהשדה `slug` ב-frontmatter אם הוגדר.
- קובץ `README.md` זה מסונן ואינו נספר כמסמך ידע.

## הוספת מסמך ידע חדש

1. צרו קובץ `.md` חדש בתיקייה זו עם frontmatter כמו בדוגמה.
2. הריצו:

   ```bash
   npm run knowledge:sync
   ```

הסנכרון מזהה קבצים חדשים/שהשתנו לפי checksum, מבצע upsert לפי slug, ומסמן כ-"archived"
מסמכים שנמחקו מהתיקייה (בלי למחוק אותם מה-DB). דורש `MONGODB_URI` ב-`.env.local`.
