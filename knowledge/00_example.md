# מסמך דוגמה

זהו **קובץ דוגמה בלבד**, שנועד לבדוק שהמערכת יודעת לסרוק קבצי Markdown, לקרוא את
ה-metadata, ולסנכרן אותו למסד הנתונים.

- אין כאן תוכן הכשרה אמיתי.
- אפשר להחליף אותו בקבצי ידע אמיתיים בהמשך.
- כל קובץ חדש שיתווסף לתיקייה `knowledge/` יופיע במאגר לאחר הרצת הסנכרון.
